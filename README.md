# cattle — 羊と宇宙船の非対称2人対戦

ハニカムの盤で羊10匹と飛行物体3機が対戦する2人用ボードゲーム。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/cattle/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

点をタップして羊を置く・動かす、飛行物体を動かす・羊を誘拐する・牽引光線で引き寄せる。
羊 10 匹を手持ちから置き切ったら盤上の羊を動かして飛行物体を身動きできなくすれば羊の勝ち、
飛行物体が羊を 3 匹連れ去れば飛行物体の勝ち。

開始時（と「もう一度」のとき）に対戦方式を選べる。「2 人で」は同じ端末で交互に操作、
「CPU が飛行物体」「CPU が羊」は Web Worker で動くコンピューターが相手側を担当する
（既定は CPU が飛行物体）。CPU の手番中は「考え中…」と出て操作を受け付けない。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
